# 世界手卫生日丨手套不是万能的，手卫生才是关键！

> 更新时间：2026-09-17 (UTC+8)

世界手卫生日

// 合理使用手套 关键永远是手卫生 //

2025年5月5日是世界手卫生日。今年主题是：“合理使用手套，关键永远是手卫生。”（It might be gloves,It's always hand hygiene.），不仅提醒合理使用手套，更是强调手卫生是“永远的关键”，手套的“合理使用”需以手卫生为前提。手卫生始终是感染防控的核心措施。

1

**手卫生：守护健康的“第一道防线”**

你知道吗？我们的双手每天会接触无数细菌和病毒，稍不留神就可能成为疾病的传播媒介。因此，**手卫生是预防感染、守护健康的基石**。无论是在医疗环境还是日常生活中，正确洗手都能有效阻断细菌、病毒的传播，保护我们自己和他人的健康。

2

**什么时候需要洗手**

世界卫生组织推荐手卫生**“五大时刻”**，请您记住“两前三后，把好五关”：

1.接触患者前

2.无菌操作前

3.接触患者体液后

4.接触患者后

5.接触患者周围环境后

4

**手套的正确使用：辅助工具，而非“免洗牌”**

手套是保护我们免受污染物和传染性物质侵害的重要工具，但它绝不能替代手卫生！记住，**手套只是辅助，手卫生才是原则！**

**如何正确使用手套？**

**1.该戴的时候一定要戴！ **

根据我国《医院隔离技术标准》，以下情况必须戴手套：

▲接触患者的体液（血液、组织液等）、分泌物、排泄物等及污染物品时，应戴一次性使用医用橡胶检查手套。

▲进行手术、换药等无菌操作以及接触患者破损皮肤、粘膜时，应戴一次性使用灭菌橡胶外科手套。

**2.戴脱手套前后必须洗手！**这就是“手卫生双保险”，确保彻底阻断感染传播。

**3.一次性手套，一次性使用！**不可重复使用，用后应视为传染性废物处理。

**4.不同患者，更换手套！**诊疗护理不同的患者之间应更换手套，防止交叉感染。

**5.破损手套，及时更换！**发现手套破损，应立即更换，避免病菌接触。

**6.戴手套不是万能的！**细菌可能通过裂口、破洞、手部活动或材料质量问题穿透手套。过度依赖手套而忽视手卫生，反而可能增加感染风险。
